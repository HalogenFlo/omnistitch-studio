# Support Policy

Thank you for using **WSI Stitching Studio**! Here is how to find help, report issues, and interact with the community.

## 1. Questions & General Discussions
- **GitHub Discussions**: Use GitHub Discussions for questions regarding how to align custom slide formats, best practices for microscopic tile scanning, or algorithm explanations.
- **Documentation**: Check our comprehensive [README.md](README.md) for quickstart guides, architecture maps, and API specifications.

## 2. Bug Reports
If you suspect you have found a bug in the alignment engine, DZI generator, or web viewer:
1. Search existing [GitHub Issues](https://github.com/Phatjhhoq8/wsi-stitching-studio/issues) to ensure it has not already been reported.
2. If unresolved, open a new issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. Include your operating system, Python version, RAM, and a minimal reproducible tile set.

## 3. Feature Requests
Have an idea for a new feature (e.g., GPU acceleration, Z-stack depth estimation, DICOM WSI integration)?
- Open an issue using our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).

## 4. Security Vulnerabilities
- For security-sensitive issues, please refer to our [Security Policy](SECURITY.md) and do **not** open public issues.
