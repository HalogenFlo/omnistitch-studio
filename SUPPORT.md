# Support Policy

Thank you for using **OmniStitch Studio**. This document explains how to request help and report problems.

## 1. Questions
- **GitHub Issues**: Open a [question issue](https://github.com/Phatjhhoq8/omnistitch-studio/issues/new) for usage and algorithm questions.
- **Documentation**: Check the [README](README.md) and [API reference](docs/API.md) first.

## 2. Bug Reports
If you suspect you have found a bug in the alignment engine, DZI generator, or web viewer:
1. Search existing [GitHub Issues](https://github.com/Phatjhhoq8/omnistitch-studio/issues) to ensure it has not already been reported.
2. If unresolved, open a new issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. Include your operating system, Python version, RAM, and a minimal reproducible tile set.

## 3. Feature Requests
Have an idea for a new feature (e.g., GPU acceleration, Z-stack depth estimation, DICOM WSI integration)?
- Open an issue using our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).

## 4. Security Vulnerabilities
- For security-sensitive issues, please refer to our [Security Policy](SECURITY.md) and do **not** open public issues.
