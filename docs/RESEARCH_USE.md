# Research-Use Evidence

JOSS requires evidence that submitted software is already being used in research. This file records verifiable uses without treating planned work as completed impact.

## Current Status

No external adoption, publication using OmniStitch Studio, or validated clinical use is currently claimed. The bundled synthetic workflow is verification material, not evidence of external research impact.

## Adding a Record

Add a dated entry after a use can be verified. Include:

- Research question and scientific domain.
- Public paper, preprint, data set, protocol, or repository URL when available.
- OmniStitch Studio version or commit identifier.
- Input data description and data-access restrictions.
- Reproducible command or workflow.
- Quantitative output or validation metric.
- Research group or contact, with permission.

Private pre-publication workflows should be described directly to JOSS editors and should not expose confidential data here.
